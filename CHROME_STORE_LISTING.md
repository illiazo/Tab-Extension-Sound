# Chrome Web Store Listing Information

## Title
Tab Sound

## Short Description (132 characters max)
Play custom sounds when tabs open and close. Customize your browsing with audio notifications.

## Detailed Description
Tab Sound is a lightweight Chrome extension that enhances your browsing experience by playing custom audio when you open or close browser tabs.

### Key Features:
- **Custom Sound Selection**: Choose from multiple sounds for opening and closing tabs
- **Easy Configuration**: Simple, intuitive options page
- **Preview Function**: Test sounds before saving your preferences
- **Lightweight**: Minimal performance impact on your browser
- **Privacy Focused**: No data collection or tracking

### How to Use:
1. Install the extension
2. Right-click the extension icon and select "Options"
3. Choose your preferred sounds for new tabs and closed tabs
4. Click "Play Preview" to test the sounds
5. Your preferences are automatically saved

### Adding Custom Sounds:
Place audio files in these folders (if you want to modify the extension):
- New tab sounds: `sounds/new_tab_sounds/`
- Closed tab sounds: `sounds/closed_tab_sounds/`

Supported formats: MP3, WAV, OGG, M4A

### Troubleshooting:
- If sounds don't play, check that the extension is enabled in chrome://extensions/
- Verify audio files are in the correct folders
- Ensure files are in a supported audio format

### Privacy & Permissions:
- This extension uses storage to save your preferences (uses Chrome Sync)
- Audio playback requires offscreen document permissions
- No personal data is collected or transmitted
- No ads or tracking
